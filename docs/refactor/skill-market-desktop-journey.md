# 桌面技能用户流程与联调

此文描述 `v2.0.1-skill.1` 本地候选的实现。测试、原生验收和公开发布需分别记录，不能以本文件代替通过证明。

## 用户使用

侧栏或画布助手的“技能”进入 `/skills`。市场页读取公共服务，详情显示版本、许可、文件和使用条件，可读取校验后的 `SKILL.md`。点击“安装此版本”才下载并校验；网页深链只打开详情，不安装、不授权、不配置模型。

安装确认展示公开审核摘要中的实际运行环境、版本、模型、时间，以及正常使用和缺少输入样例的结论；不展示私人输入输出，也不将某个测试环境的通过描述为普遍兼容。

“我的技能”可查看本机文件、启用/停用、检查市场新版本、恢复已安装的历史版本、复制为私人改写、删除本机包。停用保留文件与版本，但助手不能再选择或加载；删除会移除本机包，不影响市场发布。每轮助手选择仍由 `{skillId, versionId, contentHash}` 固定，更新不会替换历史回合的 pin。

市场依赖使用有限 ID：`beeftv.canvas`、`model.image`、`model.video`、`model.audio`。`requirementNotes` 放自然语言说明。安装不等于可执行：未知能力拒绝安装；已知影音要求允许安装，但实际使用前通过当前多模态适配器和已选凭据检查，不自动选择 WAND。图片输入目前缺乏可信模型能力合同，阻止声称必须图片理解的技能执行并说明原因；普通文字技能不依赖多模态。

能力检查覆盖用户选择、宿主加载、正文和辅助文件读取；事务内复用同一资源仓储。能力暂时不满足时保留原固定版本和恢复回执，不当作资源已删除，不自动丢弃技能。

## 作者投稿

创建/导入/私人改写默认只保存在本机。选择“准备投稿”填写名称、用途、版本、许可证和使用条件；准备阶段生成固定本机快照，不上传。

“我的投稿”连接专用投稿账号，在官网核对确认码。凭据只留在 Go 私有存储，界面与模型均不拿到 token。用户检查本机文件并勾选确认后上传私有草稿；后台重新下载并验证服务器预览，用户第二次确认才提交审核。每次修改/刷新预览重置确认，冲突不自动送审。

内置助手只可以起草、准备、查状态。当前画布有待确认计划时显示投稿入口，由人继续上述步骤。审核意见可刷新读取；官网“我的投稿”保留完整状态、改稿和通知。桌面不代替审核员、不自动已读通知。

## 深链与本地联调

外部格式固定为 `beeftv://skills/install?id=<skillId>&version=<releaseId>`。拒绝未知参数、重复参数、路径穿越、用户信息和片段。Mac 使用 Wails 2.16 `OnUrlOpen`；启动参数与后续实例使用同一解析器，按数据目录隔离实例锁。Windows 安装器注册当前用户协议；Linux DEB 桌面入口使用 `%u` 与 `x-scheme-handler/beeftv`。网页入口准备完毕后才消费启动链接。

本地使用已有 `BEEFTV_SKILLHUB_URL=http://127.0.0.1:<网站端口>/api/beeftv/skillhub/v1`，网站同源代理到隔离 SkillHub。授权响应返回同一网站的 `/skills` 根，避免测试稿件编辑误开生产站。默认仍为官网 HTTPS。桌面开发数据目录按项目约定使用 `.local/project-workbench-debug`。

新增本机只读端点：`GET /api/skills/market/releases/:skillId/:releaseId/file?path=SKILL.md&offset=0`，最多读取 32 KiB，并沿用归属、内容摘要及严格路径检查。不会把读取当作执行授权。

原生安装只使用 `scripts/update-local-beeftv-app.sh` 更新唯一正式路径；版本身份为预发布候选，macOS plist 使用数字核心版本。禁止复用已发布 `v2.0.0` 身份构建。

验收应覆盖：文字技能正常/缺输入样例、文件预览、固定版安装与历史保留、启停、私改、退回再审、版本更新、下架、未知/缺理解能力、错摘要、过期预览、重复点击和重启恢复。Windows/Linux 协议注册需要各自安装包现场验收；Go 解析测试不能替代系统协议拉起。
